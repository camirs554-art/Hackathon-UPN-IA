# Equipo 3

- **Integrantes:** Liz Guadalupe Castillo Barrientos, Danitza del Rosario Merino Amaya, Camila Estefania Romero Sulca
- **Descripción del proyecto:** Abastecimiento Inteligente Rímac es un sistema híbrido de inteligencia artificial y control humano diseñado para organizar y acelerar la entrega de ayuda humanitaria durante emergencias por inundaciones o huaycos en San Juan de Lurigancho y El Agustino.
Transforma las notas de voz informales enviadas por WhatsApp por los líderes vecinales en texto estructurado mediante IA local (faster-whisper)
